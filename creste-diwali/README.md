# Creste Diwali Gifting — landing page

Static site (plain HTML, no build step). Deploys on Vercel as-is.

Before going live, edit the CONFIG block near the bottom of `index.html`:
- whatsappNumber — e.g. 919876543210
- enquiryEmail   — where quote requests go if no form endpoint is set
- formEndpoint   — Formspree/Web3Forms URL (recommended)
- deadline       — last day to order, YYYY-MM-DD
